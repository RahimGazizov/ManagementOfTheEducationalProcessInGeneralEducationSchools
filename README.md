# Разработка архитектуры и программных компонентов информационной системы управления учебным процессом для общеобразовательной школы

## 📌 Описание проекта 

Данный проект представляет собой информационную систему, предназначенную для автоматизации учебного процесса в общеобразовательной школе.

Система обеспечивает ведение электронного журнала, просмотр успеваемости, рейтингов, расписания и аналитических отчетов для различных категорий пользователей: учитель, ученик, родитель, администратор и администрация школы.

---

## ⚙️ Используемые технологии

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQLite
- HTML, CSS, JavaScript
- MailKit / MimeKit (отправка email-уведомлений)

---

## 👥 Роли пользователей

### 👨‍🏫 Учитель
- Создание электронного журнала
- Выбор класса и предмета
- Ведение журнала (оценки, посещаемость, тема урока, домашнее задание)
- Просмотр и редактирование журналов (в течение 7 дней)

### 👨‍🎓 Ученик
- Просмотр успеваемости
- Просмотр оценок и посещаемости
- Просмотр среднего балла
- Просмотр рейтинга
- Просмотр графика успеваемости
- Просмотр расписания

### 👨‍👩‍👧 Родитель
- Просмотр успеваемости ребенка
- Просмотр оценок и посещаемости
- Просмотр среднего балла
- Просмотр рейтинга
- Контроль учебной динамики

### 🧑‍💼 Администратор
- Управление пользователями
- Назначение ролей
- Управление классами и предметами
- Просмотр логов действий
- Резервное копирование данных

### 🏫 Администрация школы
- Просмотр аналитических отчетов
- Анализ успеваемости и посещаемости
- Фильтрация отчетов по классу, предмету и периоду
- Уведомление родителей о низкой успеваемости

## 🚀 Запуск проекта

1. Клонировать репозиторий: git clone https://github.com/RahimGazizov/ManagementOfTheEducationalProcessInGeneralEducationSchools.git  

2. Открыть проект в Visual Studio  

3. Открыть терминал в корне проекта и выполнить: dotnet ef database update

4. Запустить проект: F5 / Ctrl F5

## 🗄️ База данных

В проекте используется SQLite с Entity Framework Core.  
База данных создается автоматически при выполнении миграций.

---

## 📊 Особенности системы

- Ролевая модель доступа 
- Ведение электронного журнала
- Просмотр учебной информации (оценки, посещаемость, домашние задания)
- Аналитика успеваемости учеников (средний балл, динамика, график)
- Рейтинговая система учеников (по классу и параллели)
- Формирование аналитических отчетов для администрации школы
- Email-уведомления родителям при низкой успеваемости
